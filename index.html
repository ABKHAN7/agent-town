Each desk works in its own git worktree — your checkout of the base branch is never touched. Agents can't commit/push; nothing reaches git until you run a Review yourself and click "Push". The 🌿 branch picker up top decides which branch new work starts from, and stays in sync with your repo — it updates as branches are added or removed.
≈$ is just a plan-usage estimate — if you're on a subscription (Pro) plan, this isn't an actual charge. But your rate limit is spent the same way, so avoid running more than 2-3 desks at once.
Every task except "new module" needs a module chosen — if you're not sure which one, ask 🤖, and AI will suggest a suitable module from the existing ones. To stop work partway through, use 🛑 Stop in the panel; if you missed a requirement, add it with "Continue" on the same task.
🚨 The Urgent Room is always kept empty, reserved for critical work only — fast model, AI triage skipped too. When idle, its two agents play chess with each other. For the other 5 desks, AI decides which model (haiku/sonnet/opus) fits before every task, and whether the text itself signals urgency; when idle, two of them play table tennis and the rest hang out at the table. Domain (Payroll/HR/Inventory…) is optional but improves accuracy when given. You can also describe a task by speaking with 🎤, or by giving an image/Excel/PDF via 📎 or Ctrl+V. Click ✏️ next to any agent's name to rename them.
